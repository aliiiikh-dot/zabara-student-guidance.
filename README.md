# منصة التوجيه الطلابي – ثانوية زبارة رشيد (نموذج)

واجهة عربية RTL تجريبية تعمل بدون تثبيت: افتح `index.html` في متصفح حديث.

## محتويات
- `index.html`: الهيكل والصفحات.
- `style.css`: التصميم responsive والألوان.
- `app.js`: التفاعلات والنماذج التجريبية.

## النشر التجريبي عبر Vercel
1. فك ضغط الملف.
2. أنشئ مستودع GitHub جديد وارفع الملفات الثلاثة الموجودة داخل المجلد `zabara_site` إلى جذر المستودع (لا ترفع المجلد الخارجي نفسه كمستوى إضافي).
3. سجّل الدخول إلى Vercel عبر GitHub ثم اختر Add New → Project.
4. استورد المستودع، واترك إعدادات البناء فارغة للموقع الثابت (Static HTML)، ثم Deploy.
5. استخدم الرابط الناتج للمراجعة التجريبية.

## تحذير
لا يوجد backend أو مصادقة أو تخزين موثوق أو حماية صلاحيات. التغييرات في الواجهة مؤقتة ضمن الصفحة. لا تستخدم معلومات طلاب أو أولياء أمور حقيقية. قبل التشغيل الفعلي: إعداد Supabase أو خادم موثوق، مصادقة، RLS، تحقق خادمي، سياسات خصوصية وأمن، وإجراءات موافقة الجهة التعليمية.
